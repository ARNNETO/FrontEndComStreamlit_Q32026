## Sobre o projeto

Este projeto foi desenvolvido para atender aos requisitos do Assessment da disciplina de Desenvolvimento Front-End com Streamlit. A aplicação apresenta, de forma interativa, dados e estatísticas de partidas de futebol disponibilizados pela StatsBomb, utilizando diferentes recursos visuais para facilitar a análise das informações.

## Tecnologias utilizadas

O projeto foi desenvolvido com **Python 3.13** e utiliza as seguintes bibliotecas:

* **Mplsoccer** — versão 1.8.1 ou superior;
* **Pandas** — versão 3.0.6 ou superior;
* **StatsBombPy** — versão 1.22.0 ou superior;
* **Streamlit** — versão 1.64.0 ou superior.
